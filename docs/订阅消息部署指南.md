# 订阅消息推送 - 部署与配置指南

## 📋 功能概述

基于 `docs/留存.md` 规范实现的完整订阅消息系统，包含：

- ✅ 前端授权逻辑（3个触发场景）
- ✅ 云端定时推送（3种消息类型）
- ✅ 本地 + 云端状态同步
- ✅ 额度管理与冷却期控制

---

## 🚀 部署步骤

### 1️⃣ 上传云函数

在微信开发者工具中：

1. 打开 `cloudfunctions/reminderSender` 目录
2. **右键 → 上传并部署：云端安装依赖**
3. 等待部署成功提示

### 2️⃣ 配置定时触发器（重要！）

云函数需要配置 3 个定时触发器，分别对应 3 种推送场景：

#### 方法一：通过微信开发者工具配置

1. 在 `cloudfunctions/reminderSender` 目录上**右键**
2. 选择 **触发器 → 添加触发器**
3. 按以下配置添加 3 个触发器：

| 触发器名称 | 触发频率 | 调用参数 | 说明 |
|-----------|---------|---------|------|
| `dailyCheckinTrigger` | `0 0 9 * * *` | `{"type":"dailyCheckin"}` | 每天 09:00 推送打卡提醒 |
| `expireWarningTrigger` | `0 0 10 * * *` | `{"type":"expireWarning"}` | 每天 10:00 推送到期预警 |
| `planCompleteTrigger` | `0 0 20 * * *` | `{"type":"planComplete"}` | 每天 20:00 推送结项通知 |

#### 方法二：通过 config.json 配置（推荐）

在 `cloudfunctions/reminderSender/config.json` 中添加：

```json
{
  "permissions": {
    "openapi": ["subscribeMessage.send"]
  },
  "triggers": [
    {
      "name": "dailyCheckinTrigger",
      "type": "timer",
      "config": "0 0 9 * * *"
    },
    {
      "name": "expireWarningTrigger",
      "type": "timer",
      "config": "0 0 10 * * *"
    },
    {
      "name": "planCompleteTrigger",
      "type": "timer",
      "config": "0 0 20 * * *"
    }
  ]
}
```

> ⚠️ **注意**：添加触发器后需要重新上传云函数才能生效！

### 3️⃣ 验证部署

#### 测试云函数是否正常工作

在微信开发者工具的云开发控制台，或在前端代码中调用：

## 📊 数据结构说明

### subscribe_records 集合（云端）

| 字段名 | 类型 | 说明 |
|-------|------|------|
| `_id` | string | 自动生成的文档ID |
| `openid` | string | 用户标识 |
| `planId` | string | 心愿ID |
| `authTime` | string | 最近一次授权日期 (YYYY-MM-DD) |
| `quotaUsed` | boolean | 额度是否已使用 |
| `usedAt` | Date | 使用时间 |
| `lastPushType` | string | 最后一次推送类型 |
| `lastPushDate` | string | 最后一次推送日期 |
| `rejectTime` | string | 最近拒绝日期（可选） |
| `createdAt` | Date | 创建时间 |
| `updatedAt` | Date | 更新时间 |

### 本地存储键（前端）

| 存储键 | 格式 | 说明 |
|-------|------|------|
| `subscribe_{planId}_auth` | YYYY-MM-DD | 授权时间 |
| `subscribe_{planId}_reject` | YYYY-MM-DD | 拒绝时间 |
| `subscribe_{planId}_used` | YYYY-MM-DD | 额度已使用标记 |

## 🔧 API 接口文档

### 云函数入口：`reminderSender`

#### 定时任务接口

| type 参数 | 触发时机 | 推送对象 | 说明 |
|----------|---------|---------|------|
| `dailyCheckin` | 每天 09:00 | 当日有未完成打卡的心愿用户 | 打卡提醒 |
| `expireWarning` | 每天 10:00 | 到期前3天的心愿用户 | 到期预警 |
| `planComplete` | 每天 20:00 | 当日到期的心愿用户 | 结项通知 |

#### 前端同步接口

| type 参数 | 参数 | 说明 |
|----------|------|------|
| `syncAuth` | `planId` | 授权成功后同步到云端 |
| `clearRecords` | `planId` | 删除心愿时清除云端记录 |
| `getStatus` | `planId` | 查询订阅状态（调试） |

#### 返回值格式

```json
{
  "successCount": 5,
  "failCount": 1,
  "skipCount": 10,
  "type": "dailyCheckin"
}
```

## 🎯 业务流程图

```
用户操作
   │
   ├─ 新建心愿成功 ──→ triggerAfterCreate() ──→ 弹窗请求授权
   │                                                    │
   │                                          用户同意 ──┤
   │                                                    ↓
   │                                           recordAuth()
   │                                                  │
   │                                            本地存储 + 云端同步
   │
   ├─ 打卡成功 ──→ triggerAfterCheckin() ──→ 弹窗请求授权
   │                                                   │
   │                                         用户同意 ──┤
   │                                                   ↓
   │                                          recordAuth()
   │                                                 │
   │                                           刷新7天有效期
   │
   ├─ 手动点击按钮 ──→ triggerManual() ──→ requestSubscribe()
   │
   └─ 删除心愿 ──→ clearAllRecords() ──→ 清除本地 + 云端记录


定时任务（服务端）
   │
   ├─ 09:00 dailyCheckin ──→ 查询今日待打卡心愿
   │                              │
   │                        检查 shouldPush()
   │                              │
   │                    ┌─────────┴─────────┐
   │                    ↓                   ↓
   │               有有效额度            无额度/已过期
   │                    │                   │
   │                    ↓                   ↓
   │              发送推送             跳过（静默）
   │                    │
   │                    ↓
   │              markQuotaUsed()
   │
   ├─ 10:00 expireWarning ──→ 查询到期前3天心愿
   │                             （逻辑同上）
   │
   └─ 20:00 planComplete ──→ 查询当日到期心愿
                               （逻辑同上）
```

## ⚠️ 注意事项

### 1. 订阅消息限制

- 单用户可接收的订阅消息**没有上限**（2024年新规）
- 但每次授权只有 **1次推送额度**
- 需要用户持续授权才能持续接收消息

### 2. 模板字段约束

模板ID：`sUAAtSpg266YBGZLK68uQBEDn7cr5S-Tsl1xDg4abHo`

| 字段 | 类型 | 限制 | 示例值 |
|-----|------|------|--------|
| time1 | 时间 | 24小时制 | `2024-01-15 09:00:00` |
| thing6 | 事物 | ≤20字符 | `心愿存钱打卡` |
| thing3 | 事物 | ≤20字符 | `记得完成今日存钱打卡` |

> ⚠️ **thing字段超过20字符会导致推送失败！**

### 3. 合规要求

✅ 允许：
- 用户主动操作后触发
- 打卡成功后请求授权
- 手动按钮点击触发

❌ 禁止：
- 页面加载自动弹窗
- 定时自动弹窗
- 强制授权（不授权不能使用功能）

### 4. 错误处理

| 错误码 | 含义 | 处理方式 |
|-------|------|---------|
| 40003 | openid无效 | 标记额度已用，避免重试 |
| 43101 | 用户永久拒绝 | 标记额度已用，不再推送 |
| 40037 | 模板ID不存在 | 检查TEMPLATE_ID配置 |
| 47003 | 参数错误 | 检查data字段格式 |
| 43102 | 额度不足 | 正常情况，等待下次授权 |

## 🔍 监控与调试

### 查看推送日志

在微信开发者工具中：

1. 打开 **云开发控制台**
2. 进入 **云函数 → 日志**
3. 选择 `reminderSender` 函数
4. 可查看每次执行的详细日志

### 常见问题排查

**Q: 定时任务没有触发？**
A: 检查触发器是否配置正确，上传云函数后需要重新设置触发器

**Q: 推送发送失败？**
A: 检查用户是否有有效授权、模板字段是否符合规范

**Q: 用户收不到消息？**
A: 检查用户是否在小程序设置中关闭了通知权限
