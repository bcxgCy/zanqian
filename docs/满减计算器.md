# 全网最强双十一满减计算器｜产品交互文档 V1.1
> 更新记录：V1.1 移除全部埋点相关内容；V1.0 原始版本，定位：解决市面上所有满减计算器痛点，支持淘宝/天猫/京东/抖音多平台优惠叠加、自动最优凑单、订单拆分/合并对比、凑单退货模拟、多商品分摊、预算管控。
> 市面计算器痛点复盘
> 1. 只支持单一满减，**不区分优惠叠加顺序**，算出来金额和电商结算不一致；
> 2. 无法区分券的适用范围：店铺券/品类券/平台券互斥问题，全部无脑叠加；
> 3. 不支持多店铺商品，**不知道合并下单还是拆分下单更省钱**；
> 4. 凑单只告诉你还差多少钱，**不自动推荐最优凑单方案**；
> 5. 缺少退货模拟：凑单下单后退掉凑单品，**无法模拟退款后实付、优惠回收**；
> 6. 金额分摊简单粗暴，和电商订单内单品分摊逻辑不一致；
> 7. 不支持预售定金膨胀、定金尾款分开计算；
> 8. 没有预算红线，用户容易超额消费；
> 9. 缺少明细溯源，只输出最终价格，用户不知道每一步优惠怎么扣的；
> 10. 不支持多套方案横向比价，无法快速对比A方案/B方案省多少钱。

## 1 文档概述
### 1.1 产品目标
打造双十一一站式优惠精算工具，输入购物车商品，自动模拟电商真实结算链路，**输出多套下单方案，自动选出最优省钱方案**，支持模拟凑单、退货、多平台优惠组合，每一步优惠可溯源，解决双十一复杂优惠计算难题。
### 1.2 功能范围
✅ 多商品录入（单品名称、原价、活动预售价、所属店铺、所属品类、是否参与跨店满减）
✅ 预售定金膨胀模块（定金、膨胀倍数、尾款）
✅ 多类型优惠管理：店铺券 / 品类券 / 平台券 / 跨店满减 / 会员折扣 / 红包 / 以旧换新 / 国补
✅ 优惠互斥标记（A券和B券不能同时勾选）
✅ 自动计算：合并下单 VS 拆分多单，对比总实付，推荐最优下单策略
✅ 智能凑单引擎：自动算出还差多少金额满足门槛，推荐最低成本凑单金额
✅ 凑单退货模拟：模拟「下单后退回凑单品」，计算退货后实际花费、损失优惠
✅ 单品优惠分摊（和电商结算分摊逻辑对齐）
✅ 多方案保存、横向比价（方案A / 方案B对比）
✅ 预算预警：设置预算上限，超预算标红提醒
✅ 完整计算日志，每一步优惠扣减明细可展开查看
✅ 内置平台模板：天猫、淘宝、京东、抖音优惠叠加规则模板，一键切换

## 2 核心算法规则（对齐电商真实结算顺序）
> 通用标准优惠叠加顺序（可自定义修改，适配不同平台）
> 单品活动预售价 → 店铺券（单店门槛） → 品类券（品类限定） → 跨店满减（同池商品合并计算） → 会员折扣（88VIP/PLUS） → 红包抵扣 → 以旧换新补贴 → 国补/换新补贴
> 运费**不参与任何满减/券门槛计算**，运费最后单独加在实付金额。

### 2.1 商品基础模型
每条商品数据：
- 商品名称
- 所属店铺
- 所属品类
- 商品活动价（参与优惠基数，不含运费）
- 是否参与跨店满减（布尔）
- 是否参与品类券（布尔）
- 数量
- 运费（单品/整单运费）

### 2.2 优惠模型
优惠类型：
1. **店铺券**：仅限本店商品，门槛按本店商品合计金额；一单限1张；同店铺多张券互斥。例：满200减20
2. **品类券**：限定品类商品合计，跨店同品类可合并；一单限1张。例：满1000减100（服饰品类）
3. **平台券**：全平台可用，满足总门槛即可；一单限1张
4. **跨店满减（每满X减Y）**：所有标记「参与跨店」商品金额合并累计；每满X可以减Y，上不封顶；不找零。例：每满300减50，599元只能减50，600减100
5. **会员折扣**：百分比折扣，对优惠后金额打折（如95折）
6. **红包**：无门槛，抵扣实付，可设置单订单上限
7. **定金膨胀**：定金N元，膨胀后抵M元；仅尾款部分参与各类满减/券；定金不计入跨店满减门槛
8. **以旧换新/国补**：最后一步抵扣，基于前面所有优惠结算后的金额计算补贴

> 互斥规则：同一类型优惠券，一单只能生效一张；用户可手动标记任意两个优惠互斥（例如品类券A、品类券B二选一）。

### 2.3 订单分组算法（核心亮点，市面工具缺失）
引擎自动做2套计算：
方案1：全部商品合并成**1个订单**，按合并后金额匹配所有券与跨店满减
方案2：自动按店铺拆分多订单，**每个店铺单独一单**，店铺券可以分别生效；跨店满减失效（分单）
> 引擎自动对比方案1总实付、方案2总实付，标记【推荐最优方案】，同时展示两套结果给用户。

> 进阶：支持手动自定义分组（用户手动勾选哪些商品放同一单），自定义分组方案保存为方案3/4，用于比价。

### 2.4 智能凑单引擎
输入当前商品池，选定优惠规则后：
1. 计算当前**可参与跨店满减的有效金额**
2. 算出距离下一档满减门槛还差多少金额
3. 输出推荐：**最低凑单金额 = 差额**；提示：增加≥差额的参与满减商品，可多拿XX元满减优惠
4. 同时自动计算【凑单性价比】：每多花1元，可以节省多少优惠；性价比低给出黄色警告（不建议硬凑）

### 2.5 凑单退货模拟模块（重磅功能）
场景：A商品为主品，B为凑单商品，合并下单享受满减，收货后退回B。
模拟逻辑：
1. 下单阶段：A+B合并结算，享受全部优惠
2. 退货后：按电商分摊规则，优惠按比例回收；退款金额 = 凑单品分摊后实付金额
3. 输出：退货后主品**真实落地成本**，以及「凑单操作到底省没省钱」结论；
> 红色警告：如果退货后主品成本 > 直接单独买A的价格，提示：**不建议凑单后退，会更贵**。

### 2.6 单品金额分摊算法
多商品合并订单，优惠总额按**商品有效基数占比分摊到单品**，保留2位小数；尾差自动合并至最后一件商品，保证所有单品分摊金额之和 = 订单总优惠，和淘宝/京东分摊逻辑保持一致。
> 单品分摊优惠 = 订单总优惠 ×（单品参与优惠基数 ÷ 订单全部商品基数总和）

### 2.7 预算计算
用户设置预算上限（总预算）
- 总预估实付（含运费）＞预算：结果区域标红，提示「超出预算XX元」
- 支持勾选「过滤方案」，自动隐藏所有超出预算的下单方案

### 2.8 计算精度规则
- 所有金额统一保留2位小数
- 所有优惠最低到0元，不允许出现负实付金额
- 优惠券减免金额不能超过对应商品池可抵扣总基数

## 3 页面整体结构
页面分为五大模块：【平台模板切换】→【商品清单】→【优惠库管理】→【方案计算结果区】→【方案对比/保存】

### 3.1 顶部：平台模板切换区
下拉选择：天猫/淘宝 / 京东 / 抖音 / 自定义规则
- 选择模板，自动加载该平台默认优惠叠加顺序、默认跨店满减模板；
- 支持「自定义模式」，手动拖拽调整优惠叠加顺序，保存自定义模板。

### 3.2 商品清单模块
功能：增删改商品，支持批量导入（粘贴多行文本导入）
每一行商品字段：
商品名称｜店铺｜品类｜活动价｜数量｜是否参与跨店满减｜是否参与品类券｜单品运费｜操作（删除/复制）
额外「预售开关」：打开预售，展开定金、膨胀金额输入框。
操作：
- 添加商品按钮；批量清空；批量导入；批量勾选选中商品（用于自定义订单分组）
实时校验：商品活动价不能为负数。

### 3.3 优惠库管理模块
卡片式管理所有可用优惠券/权益，**支持勾选启用、取消勾选、标记互斥**
每一条优惠卡片：
优惠名称｜优惠类型｜门槛｜减免金额｜适用范围｜互斥标记｜勾选框
操作：新增优惠；删除优惠；编辑优惠；设置互斥（选择另外一张券，二者互斥只能二选一）
示例：
✅ 店铺券：满300-30，适用店铺：XX旗舰店
✅ 品类券：满1000-100，适用品类：服饰
✅ 跨店满减：每满300-50，全店参与商品
✅ 会员折扣：95折
✅ 红包：100元无门槛

> 互斥交互：当勾选券A，系统自动置灰已经标记互斥的券B，无法同时勾选，同时悬浮提示「券A与券B互斥，不可叠加」。

### 3.4 计算结果主区域（核心页面）
点击【开始精算】，一次性生成多套方案卡片：
> 方案1：全部合并一单｜方案2：按店铺自动拆分多单｜方案3：用户自定义分组方案（如有）

每套方案卡片内展示：
1. 方案名称，【推荐最优方案】标签（自动标记总实付最低方案）
2. 订单总预览：商品总基数、优惠券合计减免、跨店满减减免、会员折扣减免、红包抵扣、运费、最终实付金额
3. 预估单件成本列表（分摊后单品实付）
4. 【查看完整计算日志】按钮：展开完整分步计算流水，每一步优惠扣减明细，清晰展示每一步公式
5. 【模拟退货】按钮：进入退货模拟弹窗，选择需要退回的商品，计算退货后主品真实成本

下方独立【智能凑单推荐】面板：
- 当前有效参与满减金额：XXX元
- 距离下一档满减门槛还差：XXX元
- 推荐凑单：增加≥XXX元【参与跨店满减商品】，可额外节省XX元
- 凑单性价比提示：绿色推荐 / 黄色谨慎凑单 / 红色不建议凑单（为了几十块优惠强行买几百无用商品）

下方【预算模块】：预算输入框，输入总预算，自动判断方案是否超标，超标标红。

### 3.5 方案对比 & 本地保存模块
- 保存方案：将当前整套商品+优惠+计算结果保存为方案快照，本地存储
- 方案对比：勾选2个或多个保存的方案，进入对比页面，横向对比总实付、优惠总额、省钱差额
- 导出明细：支持导出清单文本，方便复制发给朋友核对

## 4 弹窗交互详情
### 4.1 新增优惠弹窗
下拉选择优惠类型，动态渲染对应输入项。
- 店铺券：填写门槛、减免金额、选择适用店铺
- 品类券：填写门槛、减免金额、选择适用品类
- 跨店满减：每满X减Y
- 会员折扣：折扣比例（0.95=95折）
- 定金膨胀：定金金额，膨胀抵用金额
- 红包/以旧换新/国补：抵扣金额
保存校验：优惠减免不能大于门槛（固定满减券），校验报错提示。

### 4.2 退货模拟弹窗
1. 下拉选择要退货的商品、退货数量
2. 点击【模拟退货计算】
3. 输出：原下单实付，退货退款金额，退货后主品剩余实际花费，对比「直接单独购买主品」差价
4. 结论文字：✅划算 / ⚠️不推荐（退货后更贵）

### 4.3 计算日志弹窗
按时间顺序，逐条展示每一步计算：
示例：
1. 商品活动价合计：999元
2. 应用店铺券满300减30 → 999-30 = 969
3. 应用品类券满900-80 → 969 -80 = 889
4. 跨店每满300减50，889满足2档 → 减100，当前789
5. 88VIP95折：789 ×0.95 =749.55
6. 红包抵扣50 → 699.55
7. 运费+20
8. 最终实付：719.55元

## 5 异常与边界场景处理
|场景|交互处理|
|---|---|
|优惠券适用商品不足门槛|自动标记该券**无法生效**，灰色展示，日志写明：有效商品金额未达到券门槛|
|互斥券同时勾选|实时拦截，弹窗提示，禁止同时选中|
|跨店满减商品和非跨店商品混在一起|自动拆分基数，只有标记参与满减商品计入跨店满减统计|
|优惠叠加后金额小于0|最低实付锁定0元，日志提示：抵扣金额上限已触达|
|预售商品：定金计入门槛错误|定金不计入跨店满减/券门槛，仅膨胀后的金额在尾款阶段参与优惠计算|
|运费错误参与满减计算|运费全程隔离，不参与任何门槛计算，最后叠加到实付|
|批量导入商品格式错误|识别错误行，提示第几行解析失败，保留已成功导入商品|
|切换平台模板，原有商品/优惠冲突|弹窗提示：是否保留当前商品清单，仅重置优惠规则模板|

## 6 性能要求
1. 商品最多支持50条；优惠最多支持30条，精算响应时间≤150ms
2. 增删商品、勾选优惠实时预览更新结果，无页面卡顿闪烁
3. 本地存储保存商品、优惠、方案快照，不需要后端服务，纯前端可独立运行
