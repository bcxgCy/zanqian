# 心愿存钱｜徽章系统完整交互 PRD（合并完整版）

> 
> 文档说明：纯业务交互文档，不含 UI 尺寸、视觉风格；包含徽章规则、我的页面模块、图鉴页、解锁弹窗、新增分享社交功能；共 13 枚徽章。

## 一、全局通用基础规则

1. **永久持有**：徽章解锁后永久保留，不因金额下降、计划终止、打卡断签被回收。
2. **阶梯补发**：进度类金额徽章达标高阶，自动批量解锁未获得的低阶徽章。
3. **唯一解锁**：一枚徽章用户终身仅解锁一次，不会重复触发解锁弹窗。
4. **数据库核心字段**

- 用户 openid
- badge_id 徽章 ID
- unlock_time 解锁时间
- is_viewed 是否已查看（控制红点）
- is_first_shared 是否首次分享（控制分享奖励）

## 二、徽章获取规则

### 进度类

1. 第一桶金：成功完成**第 1 个攒钱计划**
2. 小有积蓄：累计攒钱总金额 ≥ 1000 元
3. 积少成多：累计攒钱总金额 ≥ 5000 元
4. 财富萌芽：累计攒钱总金额 ≥ 10000 元
5. 储蓄新星：累计攒钱总金额 ≥ 30000 元

### 打卡坚持类

1. 首日打卡：完成**首次存钱打卡**
2. 七日坚守：连续打卡满 7 天（不断签）
3. 月度储蓄家：连续打卡满 30 天（不断签）
4. 持之以恒：连续打卡满 90 天（不断签）

### 行为成就类

1. 计划大师：累计**创建 5 个攒钱计划**
2. 多线奋斗：同时存在**3 个进行中攒钱计划**
3. 复盘达人：累计完成**10 次存钱 / 复盘记录**
4. 重整旗鼓：计划失败 / 终止后，**重新新建攒钱计划**

## 三、我的页面「我的徽章」模块

1. 模块位置：用户资料数据区下方，功能菜单列表上方
2. 模块布局

- 左侧标题：我的徽章
- 右侧按钮：【全部 >】点击跳转徽章图鉴页
- 主体：横向滚动 scroll‑view，**仅渲染已解锁徽章**

3. 展示逻辑

- 排序：解锁时间由新到旧
- 最多展示最新 6 枚；超过 6 枚其余进入图鉴查看
- 空状态（0 枚徽章）：展示占位文案「还没有获得徽章，快去完成攒钱任务解锁吧」

4. Item 交互

- 点击徽章弹出**徽章详情弹窗**
- 未查看的新徽章右上角展示小红点；打开详情弹窗后红点清除

5. 数据刷新

- 当前页面触发解锁：弹出解锁弹窗，关闭后列表实时刷新，新徽章置顶带红点
- 其他页面解锁：不弹窗，下次进入我的页面刷新并展示红点

## 四、徽章图鉴页

1. 页面顶部 Tab 标签：进度类 / 打卡坚持类 / 行为成就类，默认选中进度类
2. 布局：3 列网格，**该分类全部徽章同时渲染（已解锁 + 未解锁），顺序固定不变化**
3. Item 交互

- 已解锁：点击弹出徽章详情弹窗
- 未解锁：点击不弹出弹窗，弱提示：暂未达成解锁条件，继续努力吧

## 五、弹窗交互

### 5.1 解锁成功弹窗

1. 触发：后端校验满足条件自动弹出
2. 文案：恭喜解锁全新徽章「XXX」
3. 底部按钮：【知道了】【立即分享】
4. 批量解锁场景：逐个弹窗，关闭一个弹出下一个
5. 关闭弹窗后，全页面徽章状态同步刷新

### 5.2 徽章详情弹窗

弹窗内容：徽章名称、成就释义文案、解锁时间
底部操作按钮：【保存图片】【分享好友】【关闭】

> 
> 未解锁徽章无此弹窗

## 七、边界特殊逻辑

1. 计划大师：删除计划不扣创建数量，徽章不回收
2. 多线奋斗：瞬时条件解锁，后续计划结束徽章不回收
3. 重整旗鼓：终身一次成就，多次重建计划不会重复解锁
4. 打卡类徽章：断签只影响高阶徽章解锁进度，已获取徽章永久保留
5. 批量解锁：顺序弹窗，全部落库保存
6. 分享：未解锁徽章禁止分享；海报必须携带用户昵称，不支持匿名
