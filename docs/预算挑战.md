# 省钱模块-自定义预算挑战 完整版产品PRD（无账本依赖·个人小程序合规版）
## 1. 产品概述
### 1.1 项目背景
小程序新增「自定义预算挑战」功能，用户可以自主创建不同场景、任意周期的个人消费预算，用于阶段性管控消费支出。
用户真实痛点：花钱无规划、日常乱消费、节假日/特殊场景容易超额透支、想省钱但没有可控的消费约束工具。

因**账本功能暂未开发**，本次预算挑战采用**纯手动录入消费**模式，完全不依赖账单数据，可快速上线、验证留存，后续账本上线可无缝兼容自动同步模式。

同时严格遵守**个人小程序合规规则**：全程单人使用、无社交、无排行、无互动、无用户数据互通，零审核风险。

### 1.2 功能定位
「自定义预算挑战」是**用户自主创建、任意场景、任意周期的个人消费管控工具**，主打「先定额度、再控消费、实时监督、到期复盘」。

### 1.3 核心用户场景
用户可自由创建任意预算场景，无固定模板限制，覆盖全部个人省钱场景：
- 日常管控：今日生活费、本周零花、月度餐饮预算
- 节假日管控：五一假期、国庆出游、周末休闲预算
- 专项克制：双11购物、换季穿搭、游戏充值、奶茶零食预算
- 长期规划：月度社交开销、季度出行经费、备考极简生活预算

### 1.4 核心价值
- 解决无规划消费问题：用预算约束替代盲目花钱
- 轻量化低门槛：手动录入、操作简单、上手即用
- 可视化激励：进度条、剩余额度、成败复盘，强化省钱成就感
- 提升用户留存：高频查看预算、录入消费，形成日常使用习惯
- 合规安全：纯单人私密数据，无任何社交违规点

## 2. 整体功能架构
### 2.1 功能模块组成
预算挑战完整链路：**新建预算 → 日常消费录入 → 实时进度更新 → 预算状态变更 → 到期自动复盘 → 归档留存**

### 2.2 核心能力
- 多预算创建：支持同时开启多个不同场景、不同周期的预算，并行生效
- 完全自定义：名称、金额、起止时间全部用户自主定义
- 手动消费录入：独立消费记录，不依赖账本
- 实时进度计算：自动统计已消费、剩余额度、超额金额、进度占比
- 全状态管理：未开始/进行中/已结束/已归档 完整状态流转
- 自动复盘总结：周期结束生成专属省钱报告
- 云端总开关：审核期可一键隐藏入口，规避审核风险

## 3. 详细产品规则（核心）
### 3.1 新建预算规则
#### 3.1.1 新建表单字段（全部一期上线）
- **预算名称**：必填，1-20字，自定义输入（支持中文、数字、字母）
- **预算总金额**：必填，正数，支持小数点后两位，最小0.01元
- **开始日期**：默认当天，支持手动选择任意过去/未来日期
- **结束日期**：必填，必须大于等于开始日期
- **超额提醒**：开关，默认开启（录入消费超额时弹窗提示）

#### 3.1.2 表单校验规则
- 名称不能为空、不能纯空格
- 预算金额必须大于0，不可为0、负数
- 结束日期不能早于开始日期
- 时间区间无上限，支持1天短期、数月长期预算

### 3.2 消费录入规则（无账本核心逻辑）
所有预算消费记录**独立存储、手动录入**，与账本完全隔离，不依赖任何账单数据。

#### 3.2.1 录入入口
仅在「进行中、未开始」的预算详情页展示【录入一笔消费】按钮

#### 3.2.2 录入弹窗字段
- 消费金额：必填，正数，保留两位小数
- 消费备注：选填，最多30字（如：奶茶、打车、聚餐）
- 消费时间：默认当前时间，支持手动修改

#### 3.2.3 录入约束（重要）
- 消费时间必须在「预算开始日期～结束日期」区间内，超出区间禁止录入，弹窗提示「消费时间不在预算周期内」
- 已结束、已归档预算禁止新增消费
- 支持单条消费记录编辑、删除，修改后实时重算预算数据

### 3.3 数据计算公式（固定逻辑）
仅统计支出，收入不计入预算抵扣
- 周期已消费 = 当前预算下所有有效消费记录金额总和
- 剩余预算 = 预算总金额 - 周期已消费
- 超额金额：剩余预算小于0时，取剩余预算绝对值；否则为0
- 进度百分比 = 已消费 ÷ 预算总金额（最大100%，超额不溢出）

### 3.4 四大状态完整流转规则
#### 3.4.1 未开始
当前时间 < 预算开始时间
- UI状态：灰色进度条，展示「未开始」标签
- 可操作：编辑预算信息、删除预算
- 不可操作：禁止录入消费、禁止归档

#### 3.4.2 进行中
当前时间 在 开始日期～结束日期之间
- UI状态：正常/预警/超额三色进度条
- 可操作：录入消费、编辑消费、删除消费、编辑预算、归档、删除预算
- 实时刷新数据，每次操作自动重算进度

#### 3.4.3 已结束
当前时间 > 预算结束日期，系统自动判定结束，无需手动操作
- UI状态：固定进度条，展示「已结束」标签，展示复盘结果
- 数据锁定：禁止新增、编辑、删除任何消费记录，保证复盘数据真实有效
- 可操作：查看详情、查看复盘、归档
- 不可操作：编辑预算、删除预算、录入消费

#### 3.4.4 已归档
用户手动归档的预算，属于历史沉淀数据
- UI状态：下沉至归档列表，不在首页主列表展示
- 所有数据完全锁定，不可修改、不可操作
- 仅支持查看详情、查看复盘

### 3.5 进度条颜色规则（UI强规范）
- 0%～80%：绿色（安全省钱区间）
- 80%～100%：黄色（临近超标预警）
- ＞100%：红色（已超额透支）

### 3.6 挑战成败判定规则
- 挑战成功 ✅：周期结束，已消费 ≤ 预算总额，展示「预算管控成功！本次共省下XX元」
- 挑战失败 ❌：周期结束，已消费 ＞ 预算总额，展示「预算超额！本次共超支XX元」

### 3.7 复盘报告规则（自动生成）
预算结束后自动生成永久复盘报告，内容包含：
- 预算基础信息：名称、预算总额、周期时长
- 最终数据：总消费金额、剩余/超额金额
- 挑战结果：成功/失败总结文案
- 消费明细列表：当期所有录入的消费记录

### 3.8 提醒规则（无审核风险纯本地提醒）
不使用微信服务通知、不订阅、不弹窗骚扰，仅小程序内即时提示
- 开启超额提醒后，**本次录入消费直接导致超额**，立即弹窗提示：「⚠️ 本次消费后，【XX预算】已超额！注意克制消费」
- 未超额无任何提醒，体验轻量化

## 4. 页面结构与交互规范
### 4.1 预算模块首页区域
页面结构：预算挑战列表区域
#### 4.1.1 功能入口
- 右上角悬浮按钮：**+ 新建预算**
- 底部固定入口：**查看全部归档预算**

#### 4.1.2 预算卡片统一UI信息
每张卡片独立展示单条预算核心数据：
- 预算名称、状态标签（未开始/进行中/已结束）
- 数据文案：已消费XX元 / 总预算XX元
- 彩色进度条
- 辅助文案：剩余XX元 / 已超额XX元

点击任意卡片，进入预算详情页

### 4.2 新建预算页面/弹窗
简洁表单布局，全部字段清晰提示，校验失败实时文案提示

### 4.3 预算详情页
#### 顶部数据区
预算名称 + 状态标签、总预算、已消费、剩余/超额金额、进度条
#### 中部操作区
- 主按钮：录入一笔消费（仅未开始/进行中展示）
- 次操作：编辑预算、归档、删除预算（按状态动态显示隐藏）
#### 底部内容区
- 消费记录列表：单条展示金额、备注、消费时间，支持长按/点击编辑删除
- 复盘报告区：仅已结束状态展示

### 4.4 归档列表页
展示所有已结束、已归档的历史预算，卡片样式简化，仅支持查看详情，无任何操作按钮，用于用户长期复盘自己的省钱习惯。

## 5. 数据库结构设计（云开发）
### 5.1 主表：budgetChallenge（预算主表）
字段清单：
- _id：记录唯一标识
- userId：用户唯一标识，用于数据隔离
- name：预算名称
- totalBudget：预算总金额
- startDate：预算开始日期
- endDate：预算结束日期
- alertEnable：超额提醒开关（布尔值）
- status：预算状态，可选值：notStart / running / finished / archived
- createTime：记录创建时间戳
- updateTime：记录更新时间戳

### 5.2 子表：budgetConsumeRecord（预算消费记录表）
字段清单：
- _id：记录唯一标识
- userId：用户唯一标识
- budgetId：关联预算主表记录ID
- amount：消费金额
- remark：消费备注
- consumeTime：消费发生时间
- createTime：记录创建时间戳
- updateTime：记录更新时间戳

### 5.3 全局配置开关（复用global_config集合）
字段：
- enableBudgetChallenge：布尔值。true展示预算全部入口；false隐藏预算模块入口，审核期一键关闭

## 6. 权限、合规与异常处理
### 6.1 合规保障（重点）
- 100%单人私密功能，所有数据绑定用户ID，仅本人可见
- 无排行榜、无分享、无对比、无评论、无互动，零社交属性
- 无任何用户之间的数据传输、查看、交互行为
- 纯个人自我管控工具，完全符合个人小程序审核规范

### 6.2 异常兜底规则
- 网络加载失败：页面展示「数据加载失败，请稍后重试」，不报错白屏
- 数据为空时：展示空状态文案「暂无预算记录，快去创建你的第一个省钱预算吧」
- 误操作删除：删除前二次弹窗确认，防止误删
- 时间异常：自动校验时间区间，禁止非法时间选择
