# 🔍 一键初始化功能排查指南

## 快速自检（按顺序检查）

### ✅ 第1步：确认云函数已上传

在微信开发者工具中查看：

```
cloudfunctions/
├── dbInit/
│   ├── index.js          ✓ 文件存在
│   └── package.json     ✓ 已有 dependencies
│   └── [☁️] 或 [○]        ← 看这个图标！
```

**图标说明：**
- **☁️ 小云朵** = 已成功部署到云端 ✅
- **○ 空心圆** = 未部署 ❌

**如果显示 ○：**
→ 右键 `dbInit` 文件夹 → 「上传并部署：云端安装依赖」

---

### ✅ 第2步：确认云开发环境已开通

点击工具栏「**云开发**」按钮，应该看到：

```
✅ 当前环境：xxx (cloud1-xxxxx)
├── 数据库
├── 存储  
├── 云函数  ← 点击这里
└── 云托管
```

**如果弹出开通引导：**
→ 按提示完成开通（需要微信扫码）

---

### ✅ 第3步：测试云函数是否可调用

在**云开发控制台** → **云函数** → **dbInit** 中：

1. 点击「**测试**」按钮
2. 输入测试参数：
```json
{
  "action": "checkStatus"
}
```
3. 点击「**执行**」
4. 查看返回结果

**预期结果：**
```json
{
  "code": 0,
  "data": {
    "ready": false,
    "collections": {
      "rooms": { "exists": false },
      ...
    }
  }
}
```

**如果报错：** 记下错误信息，继续往下看

## 🎯 常见错误及解决方案

### 错误1：`Error: 请在编辑器云函数根目录选择一个云环境`

**原因：** 项目未关联云环境

**解决：**
1. 点击工具栏「**云开发**」按钮
2. 选择或创建一个云环境
3. 重新尝试上传

---

### 错误2：`Cannot find module 'wx-server-sdk'`

**原因：** package.json 缺少依赖（或未选择"云端安装依赖"）

**解决：**
1. 确认 package.json 有：
```json
{
  "dependencies": {
    "wx-server-sdk": "~2.4.0"
  }
}
```
2. **重新上传时必须选择：**「上传并部署：**云端安装依赖****」⚠️
3. 不要选「本地安装依赖上传」

---

### 错误3：`function not found: dbInit`

**原因：** 云函数名称不匹配

**解决：**
- 检查文件名是否为 `dbInit`（不是 `db-init`）
- 检查文件夹位置是否正确：必须在 `cloudfunctions/dbInit/`
- 重新上传

---

### 错误4：前端调用无反应 / 报错

**排查方法：**

打开小程序的 **调试器 Console**，查看是否有红色错误：

#### 情况A：提示"网络错误"
```
❌ 可能原因：
  - 未开通云开发
  - AppID 配置错误
  - 网络问题
  
✅ 解决：
  1. 检查 project.config.json 的 appid 是否正确
  2. 确认云开发已开通
  3. 切换网络重试
```

#### 情况B：提示"云函数调用失败"
```
❌ 可能原因：
  - 云函数代码有 bug
  - 数据库权限不足
  - 超时（默认3秒）
  
✅ 解决：
  1. 在云开发控制台手动测试该函数
  2. 查看云函数日志
  3. 检查数据库权限设置
```

#### 情况C：点击按钮无任何反应
```
❌ 可能原因：
  - loading 状态卡死
  - confirm 弹窗被遮挡
  - JS 报错被静默捕获
  
✅ 解决：
  1. 刷新页面重试
  2. 打开 Console 查看 console.log 输出
  3. 检查是否有其他弹窗未关闭
```

---

### 错误5：初始化成功但集合不存在

**原因：** 集合创建逻辑有问题

**排查：**

在云开发控制台 → **数据库** 页面：

1. 手动刷新列表
2. 查看是否有新集合出现
3. 如果没有，查看 **云函数日志**：

```
路径：云开发控制台 → 云函数 → dbInit → 日志
查找包含【dbInit】的日志输出
```

**预期日志：**
```
【dbInit】开始完整初始化...
  ✅ rooms (房间主表)
  ✅ room_user (房间用户关联表)
  ✅ room_checkin (打卡记录表)
  ✅ room_subscribe (订阅记录表)
  ✅ room_weekly_reports (周报存档表)
【dbInit】检查索引配置...
```

## 🛠️ 强制排查方案（如果以上都不行）

### 方案A：使用微信开发者工具直接测试

1. 打开 **云开发控制台**
2. 进入 **云函数** → **dbInit**
3. 点击 **测试** 按钮
4. 使用以下参数逐一测试：

**测试1：检查状态**
```json
{ "action": "checkStatus" }
```

**测试2：创建集合**
```json
{ "action": "createCollections" }
```

**测试3：完整初始化**
```json
{ "action": "initAll" }
```

观察每次的返回结果和日志

---

### 方案B：在前端添加详细日志

修改 `miniprogram/pages/db-init/db-init.js`，在关键位置加 log：

```javascript
// 在 callCloudFunction 方法开头添加：
console.log('【dbInit调试】准备调用云函数, action=', action);

// 在 wx.cloud.callFunction 的 success 回调中添加：
console.log('【dbInit调试】云函数返回:', JSON.stringify(res.result));

// 在 catch 中已有日志，确认是否触发
```

然后在 **Console** 中查看输出

---

### 方案C：简化测试（绕过前端）

在任意页面的 `onLoad` 中添加：

```javascript
async onLoad() {
  try {
    const res = await wx.cloud.callFunction({
      name: 'dbInit',
      data: { action: 'checkStatus' },
    });
    
    console.log('测试结果:', res);
    alert(JSON.stringify(res.result, null, 2));
  } catch (err) {
    console.error('测试失败:', err);
    alert('错误: ' + err.message);
  }
},
```

保存后刷新页面，看是否弹出结果框

## ⚡ 最常见的3个坑

### 坑1：忘记选择"云端安装依赖"
```
❌ 右键 → 上传并部署（本地安装）→ 不安装wx-server-sdk
✅ 右键 → 上传并部署（云端安装依赖）→ 自动npm install
```

### 坑2：云环境未切换到刚创建的环境
```
开通了新环境但工具还在用旧环境
→ 工具栏 → 云开发 → 选择正确的环境
```

### 坐3：AppID 与云环境不匹配
```
project.config.json 中的 appid 对应的是另一个小程序的云环境
→ 确保 appid 和当前登录的小程序一致
```
