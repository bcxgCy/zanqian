# 攒钱小程序 PRD 补充：分享计划 & 复制计划模块

> 
> 并入原有徽章、海报分享 PRD，不含伪代码，只保留产品交互、规则、页面、埋点、边界、合规约束
> 核心原则：仅传递计划模板配置，不传递用户存款、进度、历史记录；无共同打卡，无互相查看数据；不做分享奖励，符合微信小程序平台规范。

## 一、模块定位

1. 分享计划：用户把自己攒钱目标的规则配置生成快照对外传播，仅输出模板，不携带本人存钱数据。
2. 复制计划：接收方通过小程序卡片 / 海报扫码打开，预览模板后手动确认，生成一份属于自己的全新空白攒钱目标。
3. 传播通路：支持小程序卡片（私聊、微信群）、海报扫码（朋友圈）两种渠道。

## 二、入口位置

1. **目标详情页**
目标信息卡片下方，并列放置按钮：生成打卡海报｜转发好友｜**分享此计划**
按钮说明文案 hover / 提示：将你的攒钱计划模板分享给好友，好友可以复制开启同款计划，不会同步你的存钱进度。
2. **目标完成页（已达成的攒钱目标）**
保留【分享此计划】按钮。即便原计划已经完成，分享出去仍然是空白模板，接收方不会拿到原用户已完成成果。

> 
> 约束：徽章弹窗内不放置该入口，徽章分享与计划分享互相独立。

## 三、分享计划交互流程

用户点击【分享此计划】，弹出操作选择菜单：

- 选项 1：转发好友（小程序卡片）
- 选项 2：生成海报（发朋友圈）

### 通路 1：转发好友 / 微信群（小程序卡片）

1. 用户选择转发好友，调用小程序原生转发。
2. 系统生成一份**计划快照**，保存计划配置，不包含原用户存钱进度、存入记录。
3. 转发卡片携带快照唯一标识，跳转目标为计划复制预览页。

### 通路 2：生成海报（朋友圈传播）

1. 用户选择生成海报，调用海报生成能力。
2. 计划分享海报渲染内容：

- 分享者头像、昵称
- 计划名称
- 计划配置信息：目标总额、计划周期、存钱规则
- 提示文案：复制这份攒钱计划，开启你的存钱小目标
- 底部小程序码，携带快照参数

3. 海报保存到相册，同时复制配套朋友圈预制文案。
4. 用户手动到朋友圈发布图片。
5. 他人扫码小程序码，解析快照参数进入计划复制预览页。

### 快照规则（业务规则）

1. 用户每次发起分享，生成全新快照记录。
2. 快照独立存储计划配置；原用户修改、删除自己的攒钱目标，**已生成的快照不受影响**。
3. 快照设置有效期 90 天；到期后快照失效，无法继续复制。
4. 做简单限流：同一目标短时间频繁分享，限制快照生成频次，避免数据冗余。

## 四、接收方：复制计划完整交互

### 触发来源：小程序卡片点击 / 海报扫码

1. 解析快照标识，跳转至【复制计划预览页】，**不自动创建计划，必须用户手动确认**。

#### 复制计划预览页页面内容

- 页面标题：来自 XXX 分享的攒钱计划
- 展示完整计划配置：计划名称、目标总金额、周期类型、存钱规则
- 页面提示文案：

> 
> 📝复制说明：
> 这是一份计划模板，复制后生成属于你独立的攒钱目标，不会获取分享人的存款、进度、历史记录。

- 操作按钮：
①【直接使用】一键复制创建
②【修改后再用】跳转新建目标表单，自动回填全部模板配置，用户自行调整参数后提交

##### 按钮行为

1. 点击【直接使用】

- 读取快照配置，创建接收人全新攒钱目标，已存金额初始为 0，进度 0%，独立数据。
- 弹窗提示：✅复制成功！已为你创建全新攒钱计划。
- 跳转至新建完成的目标详情页。

2. 点击【修改后再用】

- 跳转小程序新建攒钱目标表单页面，表单全部字段自动填充快照配置。
- 用户修改名称、金额、周期等参数，提交生成自己的攒钱目标。

### 快照失效场景

快照过期或快照不存在时打开预览页：

- 页面提示：⚠️该分享计划已失效，可请好友重新分享，或者点击下方创建自己的攒钱计划。
- 页面提供按钮，跳转普通新建攒钱目标页面。

## 五、埋点统计

1. share_plan_trigger（分享计划发起）
上报参数：快照 ID、分享渠道（card 小程序卡片 /poster 海报）
2. copy_plan_success（复制计划成功）
上报参数：快照 ID、是否修改配置（是 / 否）

统计指标：分享发起量、复制转化率，用于后续迭代评估分享功能效果。

## 六、边界场景处理

1. 分享源用户删除自己原始攒钱目标：已生成快照依旧有效，接收人可以正常复制模板。
2. 接收人已有同名攒钱计划：允许复制创建，新建计划名称自动追加「(副本)」后缀，不拦截。
3. 分享已完成的旧计划：快照仅存配置，接收人拿到始终是空白全新计划，不携带对方历史存钱成果。
4. 用户头像授权异常：复制计划逻辑不受头像状态影响，可以正常完成创建。
5. 快照过期：按失效页面逻辑处理，不报错崩溃。

## 七、合规约束（强制）

1. 禁止分享计划、复制计划给予任何奖励，禁止解锁徽章、增加权益。
2. 不实现双方互相查看存钱进度，不做共同打卡、多人排行榜。
3. 禁止打开链接直接自动创建计划，必须经过预览页面，由用户手动确认操作。
4. 所有分享不做诱导分享话术，页面文案客观描述功能。

## 八、与原有分享模块合并说明

现有分享体系分为三类：

1. 徽章分享：解锁徽章场景，生成徽章海报、转发卡片
2. 打卡 / 目标成果分享：存钱打卡、目标达成，生成成果海报、转发卡片
3. **计划模板分享（新增）**：分享攒钱规则模板，他人可复制复用，不携带个人存钱数据

> 
> 三类分享物料独立，入口互相区分，共用同一套海报生成、相册保存、小程序码、埋点底层能力。
