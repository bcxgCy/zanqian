3.1 输入框统一排版规则
- 表单标签统一放置在输入框上方，文字颜色固定为 #EEF4F1
- 错误提示文字紧贴输入框下方，字号小于输入文本，不遮挡页面元素
- 输入框内文字统一左对齐，无特殊偏移、居中样式
- 深色模式输入框禁止添加多余阴影、高光效果，保持页面通透简约
四、深色模式设计约束与避坑规范
1. 品牌主色 #68BB8F 仅用作点缀强调，页面视觉占比严格控制在 5%-10%，禁止大面积铺色，避免视觉杂乱
2. 全局禁止使用纯黑 #000000 底色，统一使用柔和深绿灰 #171F1B，有效降低夜间视觉压迫感
3. 所有正文核心文字必须使用高亮浅色 #EEF4F1，禁止使用深灰文字，保障深色模式下文字可读性
4. 全局状态色固定不变，不随意替换为绿色系，保持用户操作认知统一，避免交互歧义
5. 同一屏幕内，强品牌主色元素不超过2个，主次层级分明，保证页面视觉干净整洁
五、小程序深色模式专属 WXSS 变量（可直接复用）
可直接复制粘贴至项目 app.wxss，实现系统自动适配深色模式，无需修改页面结构
/* 雾感青柠 - 深色模式全局变量 */
@media (prefers-color-scheme: dark) {
  page {
    /* 基础全局色 */
    --page-bg: #171F1B;
    --card-bg: #2C3832;
    --primary: #68BB8F;
    --secondary: #43745A;
    --text-main: #EEF4F1;
    --text-sub: #94A99C;
    --divider: #3A4A43;

    /* 全局状态色 */
    --success: #10B981;
    --warning: #F59E0B;
    --error: #F87171;
    --info: #60A5FA;

    /* 禁用专属色 */
    --disable-bg: #37473F;
    --disable-text: #677C71;
  }
}
