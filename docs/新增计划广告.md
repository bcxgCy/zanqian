心愿存钱小程序｜激励视频广告变现正式PRD（可直接开发）
一、整体说明
1. 适配产品：心愿存钱打卡小程序
2. 广告类型：微信小程序流量主 - 激励视频广告
3. 广告时长统一配置：6～15秒（用户体验最好、流失最低、库存充足）
4. 核心合规原则：所有广告均为用户主动触发，无自动弹窗、无强制观看，基础核心功能免费，广告仅解锁增值权益
5. 包含两大变现场景：新增存钱计划解锁、打卡补打卡解锁（独立广告位、独立数据统计）
二、场景一：超出免费计划名额，看广告解锁新增计划
1. 核心产品规则
每位用户永久免费上限：3个有效存钱计划
✅ 已创建有效计划＜3个：免费无限新建，无任何限制
✅ 已创建有效计划≥3个：每新增1个计划，需观看1次完整激励视频，解锁1个专属新增名额
✅ 删除已有计划：自动释放计划占用名额，无需看广告，可直接免费新建
✅ 广告解锁的额外名额：永久有效、不清零、可累积
2. 完整交互流程
1）用户点击【新建心愿计划】按钮
2）后端校验用户当前有效未删除计划总数
3）数量判断逻辑：
- 占用数量 < 3：直接进入新建计划表单（免费）
- 占用数量 ≥ 3 && 有额外解锁名额：消耗1个名额，进入新建表单
- 占用数量 ≥ 3 && 无额外名额：弹出广告解锁弹窗
4）用户点击【观看广告解锁名额】，主动拉起激励视频
5）广告回调判断：
- 完整看完广告（onReward）：后端+1额外计划名额，弹窗提示解锁成功，自动跳转新建计划页面
- 中途关闭/加载失败：不发放名额，提示「广告未完整观看，名额解锁失败」
3. 页面UI文案
顶部状态栏文案：免费心愿计划：3个（已使用X/3）｜额外解锁名额：X个
解锁弹窗文案
标题：已达免费计划上限
正文：你已创建3个免费存钱计划，观看一段短视频，即可解锁1个额外心愿计划创建名额。
按钮：【取消】｜【观看广告解锁】
三、场景二：漏打卡，看广告解锁补打卡机会
1. 核心产品规则
✅ 当日正常打卡：完全免费，无需广告
✅ 过往过期日期：默认无法直接补打卡
✅ 用户主动选择漏打卡日期，可通过观看广告，解锁单次补打卡权限
✅ 防刷限制：单用户每日最多2次广告补打卡
✅ 同一日期仅可补打卡1次，不可重复刷广告补打卡
2. 完整交互流程
1）用户进入打卡日历，点击过往漏打卡日期
2）弹出补打卡提示弹窗
3）用户主动点击【观看广告解锁补打卡】拉起视频广告
4）广告回调判断：
- 完整看完广告：发放单次补打卡权益，允许用户提交当日打卡记录
- 中途关闭/加载失败：补打卡权限不生效，提示失败
5）后端记录当日补打卡次数，达到每日2次上限后，当日不再展示广告入口
3. 页面UI文案
补打卡弹窗文案
标题：解锁补打卡
正文：当日打卡已过期，观看短视频，即可找回本次打卡记录，延续你的30天打卡进度！
按钮：【取消】｜【观看广告补打卡】
次数上限提示：今日补打卡次数已用完，明天再来吧～
四、后端数据字段设计（必加）
1. 用户用户表新增字段
- free_plan_limit：Int，固定值3（免费计划上限）
- extra_plan_quota：Int，默认0（广告解锁的额外计划名额）
- day_repair_ad_count：Int，默认0（当日广告补打卡次数）
- last_ad_repair_time：Date（最后一次补打卡广告时间，用于每日清零统计）
2. 广告奖励记录表（通用）
记录字段：用户ID、广告场景（计划解锁/补打卡解锁）、广告位ID、观看时间、奖励内容、是否核销
作用：防重复发放、数据统计、对账、防刷风控
3. 计划表统计规则
- 仅统计未删除、有效的存钱计划
- 删除计划即时减少占用数量，自动释放名额，不消耗广告解锁名额
五、广告后台配置规范
1. 开通前提：小程序流量主开通（累计UV≥500）
2. 新建两个独立激励视频广告位（分开统计数据）
- 广告位1：新增计划解锁（6-15s）
- 广告位2：打卡补打卡解锁（6-15s）
3. 统一配置：无上限时长限制、仅用户主动点击触发、测试环境使用测试广告
六、严格合规红线（违规直接封禁流量主）
1. ❌ 禁止页面自动弹出广告，必须用户主动点击按钮才拉起广告
2. ❌ 广告未完整播放、中途关闭，绝对不发放任何权益
3. ❌ 基础功能不限广告：正常打卡、3个以内计划创建，全程免费
4. ❌ 禁止诱导点击、批量刷广告、重复回调发放奖励
5. 无广告库存时，隐藏按钮/提示「暂无广告资源，请稍后再试」
七、防刷规则（必备）
1. 补打卡：单日最多2次广告解锁，零点自动清零次数
2. 新增计划：单日最多解锁3个额外名额，防止批量刷取
3. 同一事件防重：1次广告回调仅发放1次奖励，后端做唯一校验
4. 过期日期仅可补打卡1次，不支持重复补卡
八、收益逻辑说明
1. 原有开屏广告：被动曝光收益（eCPM 5-10元），作为基础收益
2. 新增双场景激励广告：用户主动观看（eCPM 15-30元），收益远高于开屏
3. 场景贴合用户刚需：想多建计划、想补救打卡记录，用户接受度高，完成率高，不伤留存
九、隐私协议补充内容
本小程序接入微信流量主激励视频广告，用户可通过主动观看广告的方式，解锁额外存钱计划创建名额、补打卡权限，广告展示均为用户主动触发，不强制观看。

十、现网实现说明（2026-09-22）
1. 新增计划广告逻辑采用“保存时收口”方案：
- 所有“新建计划”入口均可直接进入新增页面，不在入口页做广告拦截。
- 用户点击新增页面【去设置并加入计划】后，由后端统一校验是否超出免费名额。
2. 新增计划保存链路：
- 第一次调用 addPlan：若达到免费上限且无额外名额，后端返回错误码 PLAN_ADD_NEED_AD。
- 前端收到 PLAN_ADD_NEED_AD 后，弹出解锁弹窗并在用户主动点击后拉起激励视频。
- 广告完整播放后，前端调用 grantPlanAddQuotaByAd 发放 1 个额外名额（后端写入广告奖励记录并做幂等防重）。
- 发放成功后前端自动重试 addPlan，后端扣减 1 个 extra_plan_quota 并创建计划。
3. 安全与一致性：
- 前端不通过“已看广告=true”直接放行，必须由后端先写入可用名额后，再次提交新增计划。
- 即使用户绕过页面流程直接调用 addPlan，只要无额外名额仍会被后端拒绝。
