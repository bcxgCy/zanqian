2. 产品定位与核心价值
2.1 模块定位
【省钱】Tab 是独立于「存钱目标」的节流体系：
存钱 = 主动赚钱攒目标
省钱 = 被动克制减少乱花钱
两者组合形成完整闭环：一边攒钱、一边少花钱。
2.2 核心用户痛点
- 冲动消费多，买完后悔
- 想省钱但坚持不下来，缺监督
- 不知道钱该不该花，缺外部决策
- 看不到自己省下的成果，没有激励
2.3 核心业务闭环（定稿）
开启省钱挑战约束日常消费 → 想买东西产生冲动 → 发起消费评估冷静决策 → 投票/替代方案辅助判断 → 放弃购买产生省钱金额 → 挑战打卡积累省钱金额 → 顶部汇总全部省钱数据 → 优质记录自愿同步广场获得正向激励
3. 视觉规范（全局强制统一）
所有页面 100% 统一省钱主页风格
- 页面底色：米白 #F8F6F0
- 组件卡片：纯白圆角、轻微阴影
- 顶部总结卡片：蓝绿渐变高亮（核心数据突出）
- 主按钮：深绿色胶囊按钮
- 文字层级：金额加粗放大、标题加粗、辅助文案浅灰
4. 核心数据计算规则（最重要、开发必须严格执行）
4.1 总省钱金额公式
合计总省钱 = 挑战累计省钱 + 评估放弃购买省钱
4.2 省钱挑战金额计算
- 用户创建挑战填写「每日预估省钱」
- 打卡成功：当日金额累计进入总省钱
- 打卡失败（违反规则）：连续天数清零、对应累计金额回滚
- 中断挑战：不再继续累计
4.3 消费评估省钱计算
- 审批单最终状态 = 放弃购买 → 累加商品价格至总省钱
- 最终购买、待决策、过期未结算 → 不统计
5. 【省钱主页】页面完整结构与交互
页面从上至下固定四层结构，不乱、不挤、层级清晰
5.1 第一层：顶部省钱总结卡片（全局仪表盘）
展示：
- 💰 挑战累计省下金额
- 🛑 评估放弃购买省下金额
- ✅ 合计总省钱（放大高亮主数据）
交互：下拉刷新实时更新所有数据
5.2 第二层：两大功能入口（双卡片并列）
- ⚖️ 消费审批：进入审批列表
- 🎯 省钱挑战：进入挑战列表
5.3 第三层：我的进行中（私有数据）
- 进行中消费审批卡片（最新1条）
- 进行中省钱挑战卡片（最新1条）
- 未打卡红点提醒、快捷打卡按钮
5.4 第四层：省钱广场（上滑加载）
仅展示用户自愿同步公开的内容
包含：公开审批单、已完成公开挑战
上滑分页加载、只读浏览、可投票、不可编辑
6. 省钱挑战模块完整PRD
6.1 模块能力
模板快速创建、自定义创建、每日打卡、进度统计、金额累计、历史复盘、广场同步
6.2 挑战列表页
顶部 Tab：进行中 / 历史挑战
进行中卡片字段：
- 挑战名称、周期、已坚持/剩余天数
- 每日省金额、累计省金额
- 今日打卡状态（红点待打卡）
- 按钮：今日打卡 / 已打卡、查看详情
下方模板区：7天不喝奶茶、7天不点外卖、7天不打车、自定义
6.3 创建挑战页
必填：挑战名称、周期、每日预估省钱
选填：挑战说明、同步到广场（默认关闭）
创建成功自动跳转详情页、同步首页数据
6.4 挑战详情页（核心联动页）
- 可视化进度条
- 打卡日历（成功绿、失败灰、未到空白）
- 累计省钱数据展示
- 核心联动入口：快捷发起消费评估
- 修改说明、放弃挑战
规则：不可修改周期与单日金额，防止统计错乱
6.5 打卡弹窗
每日二选一：
- 今日无违反 → 连续天数+1、金额累计
- 今日违反 → 连续清零、金额回滚
单日仅可打卡一次
6.6 历史复盘页
- 展示成功/失败标签、完整周期、总省钱金额
- 支持手写复盘笔记
- 支持同步/取消同步广场
- 一键复刻新建同款挑战
7. 消费审批（消费评估）完整PRD
7.1 功能定位
用户购买前「决策拦截工具」，解决冲动消费
7.2 审批列表页
Tab：我发起的 / 我评估过的
状态：冷静中、投票中、已出结果、已放弃、已购买
7.3 发起审批页
核心字段：
- 物品名称、价格、购买理由、替代方案
- 审批模式：单人审批 / 多人奇数投票
- 冷静期可选：24/48/72小时
- 是否同步广场（默认不同步）
7.4 审批详情投票页
投票选项：
- 值得买
- 没必要买
- 可以买但找替代
- 建议再等等
可填写评论、替代建议
最终放弃购买 → 计入省钱总额
8. 省钱广场完整规则（风控+隐私）
- 所有内容默认私密
- 仅用户手动勾选「同步广场」才公开
- 可随时关闭同步、即刻下架内容
- 广场内容只读、脱敏、不可篡改
- 上滑分页加载，轻量化社区
9. 安全风控规则（上线强制）
所有用户输入文本必须经过微信官方内容安全校验：
- 挑战说明、打卡备注、复盘笔记
- 消费审批理由、评论、替代方案
校验失败直接拦截，禁止提交，满足小程序审核规范
10. 页面完整跳转链路
省钱主页 → 消费审批列表 → 发起审批 / 审批详情
省钱主页 → 省钱挑战列表 → 创建挑战 / 挑战详情 / 复盘
挑战详情 → 快捷发起消费评估（核心闭环）
主页上滑 → 省钱广场 → 广场只读详情
