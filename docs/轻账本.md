# 轻账本Tab 产品PRD（无数据库代码字段，多账本，联动24h冷静期｜产品最优性复盘）
> 独立Tab，云开发，纯单人私密，轻量化多账本，联动省钱Tab的24小时冷静期；移除所有数据库字段定义，只保留产品层面业务、页面、交互规则。

## 先回答：当前方案是不是最优轻账本？
### ✅ 优点（符合小程序轻量化定位）
1. **边界控制很好**：砍掉资产负债、账户、转账、OCR、导出等重功能，核心只做「记一笔 + 分账本月度统计 + 消费结构可视化」，开发量可控，用户上手快，不会像大型记账App那样臃肿。
2. **多账本设计克制**：上限5个账本、默认账本不可删、一期不支持账单跨账本迁移，避免复杂度爆炸，满足用户「分场景记账（日常/育儿/旅行）」核心诉求，又不引入复杂财务逻辑。
3. **和现有冷静期联动是差异化亮点**：别的记账工具没有冲动消费前置拦截+事后记账的闭环，是你小程序独有的价值。
4. **数据合规安全**：纯单人，无社交、无UGC，小程序审核风险极低。

### ⚠️ 当前方案存在3处可优化短板（不是致命缺陷，但会影响使用体验，轻账本追求极简，需要修正）
1. **记账弹窗不能切换账本**：现在要求必须回到首页切换账本才能换账本记账。用户记账时临时想换账本，需要关闭弹窗、返回首页切换，操作链路长。👉 优化：在「记一笔」弹窗顶部增加账本下拉选择，不用退出记账弹窗。
2. **缺少全局总览视角**：现在所有统计都局限在**单个账本内**。用户想一次性看所有账本合计总收入、总支出、总结余，需要来回切换账本。👉 优化：账本选择器增加一个【全部账本】选项，汇总所有账本数据（饼图依旧建议只保留单账本，全部账本只放数字汇总，避免饼图信息过载）。
3. **空状态场景覆盖不全**：两种空状态：①当前账本没有账单；②用户新建了账本，但从来没有记过账。两种场景引导文案要区分。

> 结论：**原方案基础很好，微调上面3点，就是适合嵌入你小程序的最优轻账本方案。**

# 优化后完整PRD（去掉数据库字段，已并入上面3处优化）
## 一、产品概述
### 1.1 背景
省钱Tab内的24小时冷静期可以拦截冲动消费，但缺少日常收支记录能力。市面上记账工具两极分化：要么功能过重，一堆资产、账户、理财功能，记账步骤繁琐很难坚持；要么过于简单，无法区分多场景开销。
轻账本作为独立Tab，主打快速流水记账，支持多账本分开管理不同场景开销，同时和冷静期打通，形成「冲动拦截 → 消费后记账复盘」完整省钱闭环。

### 1.2 功能定位
独立Tab【轻账本】，与省钱Tab同级。
核心定位：极简多账本个人收支流水账本，快速录入账单、分账本独立月度复盘，支持查看全部账本汇总，联动24h冷静期标记非必要消费。
- ✅ 做：多账本创建/切换、收支录入、消费分类、必要/非必要消费标记、账单编辑删除、单账本月度汇总、支出饼图、全部账本汇总、账单筛选搜索
- ❌ 不做：账本转账、资产负债、多账户管理、账单导入、OCR识别、理财、社交分享、账单导出

### 1.3 用户痛点
1. 记账步骤繁琐，操作多，坚持不下来；
2. 所有账单混在一起，无法单独看旅行、育儿等专项开销；
3. 无法区分刚性必要支出和冲动非必要消费；
4. 想快速看所有账本合计收支，需要手动切换账本相加。

### 1.4 核心价值
1. **低门槛记账**：最快2步完成一笔收支记录；
2. **分账本隔离统计**：不同场景账单相互隔离，独立复盘；支持一键查看全部账本合计收支；
3. **省钱模块联动**：冷静期确认购买的商品，可直接写入轻账本，自动标记非必要消费；
4. **完整省钱闭环**：轻账本复盘已经花出去的钱；冷静期拦截还没花出去的冲动消费；省钱挑战设定存钱目标。

## 二、核心功能逻辑
### 2.1 多账本基础规则
1. **默认账本**：用户首次进入轻账本，自动创建【日常账本】，不可删除，支持修改账本名称和描述。
2. **新建账本**：用户手动新增账本。账本名称1~12字符，同用户下账本名称不可重复；可选填写账本描述（最多30字）；一期不支持自定义账本图标。
3. **账本上限**：最多5个账本（含默认日常账本），控制复杂度。
4. **账本数据隔离**：账单归属指定账本；切换账本后，页面统计、饼图、账单列表全部切换为当前账本数据。新增【全部账本】选项，选中后只展示所有账本合并的收支数字汇总，**不生成合并饼图**。
5. **账本操作**
    - 默认账本：可编辑名称、描述，不可删除
    - 用户新建账本：可编辑名称描述，可删除；删除账本弹出强二次确认，删除后账本内所有账单永久清除，不可恢复。
6. **记忆上次选择**：退出轻账本Tab前选中的账本，下次进入自动恢复选中状态。

### 2.2 轻账本Tab首页页面结构
页面从上到下：
1. 顶部：账本下拉选择器（选项：全部账本、日常账本、自定义账本列表） + 月份选择器
2. 汇总卡片：
    - 选中【全部账本】：展示**所有账本合计**本月总收入、总支出、总结余
    - 选中单个账本：展示**当前账本**本月总收入、总支出、本月结余
3. 饼图卡片：仅在选中**单个账本**时展示本月支出分类占比；卡片下方小字展示当前账本本月非必要消费总额；选中【全部账本】时隐藏饼图。
4. 账单流水列表：选中单个账本时，展示当前账本账单；选中全部账本时，展示所有账本账单，账单条目标注归属账本名称。账单按日期倒序分组；非必要消费账单带有橙色标签。
5. 悬浮固定按钮：【+记一笔】
6. 底部入口：【全部账单】、【账本管理】

### 2.3 【账本管理】页面
入口：轻账本首页底部【账本管理】
页面内容：
- 账本列表：展示全部账本，当前选中账本高亮标记
- 单条账本卡片：账本名称、描述、本月简要收支数据
- 单条操作按钮：【设为当前账本】【编辑】【删除】；默认账本隐藏删除按钮
- 顶部按钮：【+新建账本】
新建/编辑账本弹窗：账本名称（必填）、描述（选填），保存/取消。

### 2.4 【+记一笔】底部弹窗（核心优化：弹窗内可切换账本）
弹窗字段：
1. 账本下拉选择：可直接在弹窗切换归属账本，默认带入首页选中账本
2. 收支类型：单选【支出】/【收入】，默认选中支出
3. 金额：数字键盘输入，保留两位小数，必填
4. 分类选择（横向滚动图标+文字）
    - 支出预置分类：餐饮、通勤、购物、娱乐、居住、医疗、人情、其他
    - 收入预置分类：工资、红包、兼职、理财、其他
5. 消费属性单选：必要支出 / 非必要消费，默认必要支出
6. 日期选择：默认当前时间，支持修改，用于补录历史账单
7. 备注：选填，最多20字
8. 底部按钮：【保存】【取消】

> 交互优化：打开弹窗自动聚焦金额输入框；最少2次点击完成记账。

### 2.5 账单详情与编辑
点击流水列表账单条目，打开详情弹窗
- 账单归属账本不可修改（一期不支持账单跨账本迁移，降低复杂度）
- 可编辑内容：收支类型、金额、分类、消费属性、日期、备注
- 支持删除本条账单，删除弹出二次确认；删除后对应账本统计、饼图实时刷新。

### 2.6 全部账单页面
入口：轻账本首页【全部账单】
页面顶部：账本下拉选择器 + 月份选择器 + 筛选器 + 搜索框
- 筛选条件：全部账单 / 仅支出 / 仅收入；必要支出 / 非必要消费
- 搜索：按备注、分类搜索账单
- 列表：时间倒序排列，下拉刷新，上拉加载更多历史账单；选中全部账本时，每条账单标注归属账本名称。

### 2.7 月度统计与饼图规则
- 选中单个账本：统计范围=当前账本+选中月份，计算总收入、总支出、结余；饼图统计当前账本支出分类占比，金额过小的分类自动合并为「其他」；单独统计本月非必要消费金额。
- 选中全部账本：只汇总所有账本当月收支数字，不绘制合并饼图，避免多账本数据混杂导致图表失去参考意义。

### 2.8 和24小时冷静期联动规则
1. 在冷静期页面，用户点击【确认购买】，弹窗附带选项：自动记录到轻账本，默认勾选；
2. 下拉选择目标账本，默认选中日常账本；
3. 确认后自动新建支出账单：自动带入物品名称作为备注，金额带入预估价格，消费属性自动标记为非必要消费，分类默认购物，用户可手动修改分类。

### 2.9 边界与空状态规则
1. 删除账本：强二次确认，删除账本连同账本内所有账单一并清除，不可恢复；
2. 账本切换：切换选项，页面所有统计、图表、账单列表实时刷新；
3. 补录账单：账单归属选中账本与选中日期，自动纳入对应月份统计；
4. 空状态区分：
    - 空状态A：当前账本没有任何账单：文案「记录每一笔收支，看清钱流向」，放置快捷【记一笔】按钮
    - 空状态B：账本列表存在账本，但所有账本都没有账单：文案「还没有任何账单，开始记录你的第一笔收支吧」

## 三、页面&交互详细设计

- 顶部一行：账本下拉选择器 + 月份选择

- 饼图卡片（仅单账本模式）：本月支出分布；小字：本月非必要消费：¥XXX

- 悬浮【+记一笔】固定页面底部
- 底部：【全部账单】【账本管理】

账本列表展示全部账本；当前账本高亮；【+新建账本】；每条账本卡片【编辑】【设为当前账本】【删除】（默认账本无删除）

### 3.3 新建/编辑账本弹窗
账本名称输入框（必填）、描述输入框（选填）、保存 / 取消

### 3.4 记一笔弹窗（底部Sheet）
顶部账本下拉切换；收支Tab切换；金额输入框唤起数字键盘；横向滚动分类选择；消费属性单选；日期、备注；底部保存按钮。

### 3.5 账单详情弹窗
展示：归属账本、类型、金额、分类、消费属性、日期、备注；操作按钮：【编辑】【删除】【关闭】

### 3.6 全部账单页面
顶部：账本下拉 + 月份选择 + 筛选器 + 搜索框；账单列表；下拉刷新，上拉加载更多历史账单。

## 四、合规与异常处理
### 4.1 合规保障
纯单人私密数据，没有UGC、社交、分享功能，符合小程序审核规范；所有账本、账单数据仅本人查看，无数据对外暴露；不主动推送订阅消息。

### 4.2 异常兜底
1. 离线：本地缓存当前查看账本的最近账单，联网后自动同步云端；
2. 金额校验：禁止输入负数，金额上限999999.99；
3. 数据安全：用户只能读写自己创建的账本和账单；统计计算放在云服务侧，前端无法篡改统计结果；
4. 多设备同步：换设备登录小程序，账本列表、账单数据从云端拉取，保持一致。

## 五、版本迭代规划

1. 独立轻账本Tab页面；
2. 多账本：默认日常账本，新建/编辑/切换/删除账本，最多5个；支持【全部账本】汇总查看；
3. 记一笔弹窗，弹窗内直接切换账本；收支录入、分类、必要/非必要标记；账单编辑删除；

5. 全部账单页面：账本、月份筛选，账单搜索；
6. 冷静期确认购买，可选择账本，自动写入账单，标记非必要消费。

6. 本月与上月消费对比。

## 六、整体产品闭环总结
1. **轻账本（多账本）**：分场景记录已经消费的资金，复盘消费结构；支持全部账本快速看全局收支；
