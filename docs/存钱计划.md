# 存钱计划

# 主页面（居中）

## 顶部设计：存钱计划概览

- 剩余金额（¥19210）

    - 目标：¥xxxxx

    - 已存：¥xxxx

## 下半部分：本人存钱计划列表

- 栏目按钮【存钱计划\>】，点击进入二级页面，展示当前存款结果

    - 可支持按月、按年查看

    - 存钱总览：存入、目标剩余、日均存入

    - 存钱统计：

        - 柱状图：横坐标（日），纵坐标（钱）

        - 折线图：横坐标（日），纵坐标（钱）

        - 圆环图：环中间显示总钱数，圆环分别展示不同存钱计划占比

- 【添加按钮】添加存钱计划：

    - 点击跳转二级页面，支持输入存钱计划明细

        - 存钱目的；存钱icon图标；存钱目标金额

        - 设置存钱计划：

            - 选择预设存钱计划：365存钱法、52周存钱法等。点开对应条列显示文字说明

            - 自定义存钱计划：点击对应条列，给两个输入框【钱数：N元】【频次：每天/周/月】，输入存钱起止时间

        - 点击【去设置】按钮，则应用该方案，返回首页，并在首页存钱计划列表展示该条目

- 存钱计划条（可设置多条）

    - icon图；存钱目标外显；已存入金额；存入目标；百分比进度（含进度条）；存钱计划

    - 点击计划条，进入二级页面

        - icon、存钱目的、存钱目标金额、存钱方案

        - 进度条：已存入、百分比、未存入、存钱开始时间、坚持天数

        - 存钱详情：

            - 如有存钱预设计划：按照计划列举每期应存金额，无限下滑；

                - 点击对应模块，弹出半屏进行输入：存入金额、存钱日期、备注说明

                - 对应模块完成颜色加深、对应模块未完成、同色系浅色

            - 如没有用预设存钱方案：按照用户输入的方案列举每期应情况，无限下滑（应用用户设置的起止时间）

                - 点击对应模块，弹出半屏进行输入：存入金额、存钱日期、备注说明

                - 对应模块完成颜色加深、对应模块未完成、同色系浅色

# 计算器

- 整体逻辑：输入存钱目标，选择存钱计划，给出预计达成时间

- 页面设计（主要内容）

    - 输入存钱目的；存钱icon图标；存钱目标金额

    - 选择存钱方案：存钱方案预设按照列表展示，点击对应列表条展开，文字说明存钱计划

        - 自定义存钱计划：

            - 目标钱数：N元

            - 存入方式：

                - 按固定频次：天、周、月

                - 按目标结束时间：xx年xx月xx日；输入存入频次；是否随机金额

            - 给出计算结果

                - 按固定频次均分：目标金额/存入频次=预计完成时间\+期数\+每期金额

                - 按目标结束时间：

                    - 不随机金额：结束时间/存入频次=存钱期数；目标金额/存钱期数=每期金额

                    - 随机金额：结束时间/存入频次=存钱期数（每期存入金额随机拆分）=存钱期数\+每期金额

    - 点击计算，跳转二级页面，给出预计达成时间及每期存钱金额

        - 每期金额、期数列表（表格展示：期数、当期存入金额、累计存入金额、剩余待存入金额）

        - 点击【去设置】按钮，则应用该方案，返回首页，并在首页存钱计划列表展示该条目（应用该设置的存钱起止时间）

        - 点击返回，返回上一页面

    - 预设存钱方案一览

        - N个存钱方案icon顺序排列，点击弹起半屏，文字说明对应存钱方案具体内容
