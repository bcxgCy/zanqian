## 一、数据库集合创建（必须手动操作）

在**微信云开发控制台** → **数据库** 中，依次创建以下集合：

### 1. rooms（房间主表）
```
集合名称：rooms
权限设置：仅创建者可读写，所有人可读
```

**字段说明：**
| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| _id | auto | 是 | 自动生成的记录ID |
| ownerOpenid | string | 是 | 房主openid |
| roomCode | string | 是 | 6位纯数字房间码（唯一） |
| roomName | string | 是 | 房间名称 |
| roomDesc | string | 否 | 房间简介 |
| roomNotice | string | 否 | 房间公告 |
| maxMember | number | 是 | 最大人数（50/100） |
| allowFreeJoin | bool | 是 | 是否允许自由加入 |
| allowOuterCheckIn | bool | 是 | 是否允许外部打卡 |
| openRank | bool | 是 | 榜单是否对成员可见 |
| autoReport | bool | 是 | 是否自动生成周报 |
| reportPush | bool | 是 | 周报是否推送通知 |
| status | string | 是 | 状态：active/dissolved |
| blackList | array | 否 | 黑名单openid列表 |
| inviteTokens | array | 否 | 邀请凭证列表 |
| memberCount | number | 是 | 成员数（冗余字段） |
| createTime | Date | 是 | 创建时间 |
| updateTime | Date | 是 | 更新时间 |

### 2. 部署定时任务云函数 `roomScheduler`
```bash
# 右键 cloudfunctions/roomScheduler 文件夹
# 选择「上传并部署：云端安装依赖」

# 然后右键 → 「配置定时触发器」
# 或手动编辑 config.json 后重新上传
```

### 3. 配置定时触发器
在**微信云开发控制台** → **云函数** → `roomScheduler` → **触发器**：

#### 触发器1：每日提醒
```
名称：dailyReminder
Cron表达式：0 0 20 * * * *
说明：每天20:00执行
```

#### 触发器2：周报生成
```
名称：weeklyReport
Cron表达式：0 0 10 * * 1
说明：每周一10:00执行
```

> ⚠️ 如果使用 config.json 方式配置，上传后会自动创建触发器。

## 七、常见问题排查

### Q1: 创建房间失败？
- 检查 `rooms` 集合是否存在
- 检查云函数是否部署成功
- 查看云函数日志

### Q2: 加入房间提示"权限不足"？
- 检查 `room_user` 集合权限
- 确认房间状态为 `active`

### Q3: 订阅按钮点击无反应？
- 确认在真机调试环境（开发者工具可能不支持）
- 检查模板ID是否正确配置
- 查看控制台是否有错误日志

### Q4: 定时任务未执行？
- 检查触发器是否配置成功
- 在云开发控制台查看触发器执行日志
- 手动调用测试

### Q5: 榜单数据不显示？
- 检查 `openRank` 设置
- 确认有成员打卡数据
- 刷新页面重试

## 八、性能优化建议（生产环境必做）

### 1. 数据库索引
务必按照上述说明创建索引，否则查询会全表扫描！

### 2. 打卡记录清理
建议每月清理一次历史打卡记录（保留最近3个月）：
```javascript
// 可添加到 roomScheduler 作为月度任务
const threeMonthsAgo = new Date(Date.now() - 90 * 24 * 60 * 60 * 1000);
await db.collection('room_checkin')
  .where({ createTime: _.lt(threeMonthsAgo) })
  .remove();
```

### 3. 集合数据量监控
- rooms: 通常 < 10000 条
- room_user: 取决于用户量
- room_checkin: 增长最快，需定期清理
- room_subscribe: 与 user 表规模相当
