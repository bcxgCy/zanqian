# 🧠存钱选手趣味小测试（共 10 题｜小程序内 H5 弹窗 / 内嵌页面）

> 
> 定位：做完 10 道选择题，自动生成用户存钱人格标签，输出专属评语 +**匹配小程序最合适的存钱打卡计划**，引导直接跳转对应计划创建页；适合做分享裂变，结果页支持生成分享图。
> 题型：全部单选，每题 A/B/C 三个选项，统计选项倾向，最后计算人格。

## 10 道测试题目

1. 发工资当天你第一反应？
A 先犒劳自己，想买的东西先安排，剩下再存
B 固定先转一笔钱存起来，剩余再消费
C 看心情，有钱就存，没钱就算
2. 看到直播间 / 短视频种草好物，你的行为？
A 冲动下单，喜欢就买，很难忍住
B 加入收藏，冷静 3‑7 天再决定要不要买
C 几乎不被种草，非刚需绝不消费
3. 每月实际存钱情况？
A 几乎存不下，月光或者结余很少
B 能存一部分，但经常中途破功
C 可以稳定存下预设金额
4. 如果存钱计划中断 1‑2 天，你会？
A 直接摆烂，干脆放弃整个计划
B 稍微遗憾，调整后继续坚持
C 无所谓，补上记录继续打卡
5. 更能接受哪一种存钱节奏？
A 短周期，7‑15 天快速看到成果
B 中等周期，30‑100 天循序渐进
C 长期持久战，半年、一年慢慢积累
6. 意外多出一笔小钱（红包 / 奖金），你会？
A 直接拿来吃喝玩乐花掉
B 一半花一半存起来
C 全部归入存钱小金库
7. 面对临时开销（朋友聚餐、临时购物）
A 没有预留预算，花完挤压存款
B 有备用小金库，不打乱存钱目标
C 想到再说，走一步看一步
8. 关于打卡坚持这件事
A 需要强激励，很容易三分钟热度
B 可以坚持，但需要提醒督促
C 自律很强，不需要提醒也能完成
9. 你的存钱核心动机？
A 想攒钱，但没有明确目标，玩玩而已
B 有小目标，买手机、旅行这类短期心愿
C 大额目标，买房、储备应急金等长期目标
10. 对于存钱失败你的心态
A 很挫败，会否定自己
B 当成经验，调整方案重新再来
C 看淡得失，计划灵活调整就好

## 人格结果（4 类存钱选手）

### ① 热血冲动型选手｜A 选项占比最高

**测试评语**
热情满满但是抵挡不住消费诱惑，很容易开局猛，中途摆烂。不建议直接上 365 天长周期！
✅系统推荐计划：7 天打卡 →15 天打卡，先从小周期建立成就感，再慢慢升级难度。

### ② 摇摆挣扎型选手｜B 选项占比最高

**测试评语**
心里想存钱，但现实总被各种开销打乱，经常反复横跳。自律中等，需要阶段性正向反馈。
✅系统推荐计划：30 天打卡 /100 天挑战，适合中等周期，配合日历打卡视图监督自己。

### ③ 稳扎稳打型选手｜C 选项占比最高

**测试评语**
消费克制，目标感强，执行力在线，不容易被外界消费裹挟。
✅系统推荐计划：100 天挑战 /365 天全年打卡，适合长期大额心愿，发挥你的优势。

### ④ 佛系随缘型选手｜ABC 分布均衡

**测试评语**
存钱全看缘分，不强求自己，拒绝焦虑式攒钱。不适合高强度打卡。
✅系统推荐计划：自定义存钱计划，不用强制每日打卡，随心记录存钱即可。

## 小程序产品落地细节

1. 交互：首页弹窗 / 心愿页入口：「测测你是什么存钱选手✨」；答题完成直接出结果卡片，卡片内置按钮【立即开启推荐计划】跳转对应存钱方案创建页。
2. 裂变：结果页支持生成分享图（适配小程序分享 5:4 标准尺寸），用户可以分享到社交，好友点开也进入测试。
3. 埋点：记录用户答题结果、跳转计划成功率，看哪一类人格转化率最高。
4. 趣味小彩蛋：结果附带 emoji 标签，例如：🔥冲动选手、⚖️摇摆选手、🛡稳扎选手、☁️佛系选手。
