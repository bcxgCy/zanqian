# 微信小程序云开发项目

基于微信云开发的小程序工程，包含小程序端与云函数基础结构。

## 目录结构

- `miniprogram/` — 小程序前端代码
- `cloudfunctions/` — 云函数代码

## 开始使用

1. 在微信开发者工具中打开本项目
2. 在 `miniprogram/app.js` 中配置云开发环境 ID（`env`）
3. 右键 `cloudfunctions/quickstartFunctions` 目录，选择「上传并部署：云端安装依赖」
